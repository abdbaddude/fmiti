      Product

      Nigeria National Investment Conversion & Delivery Assurance NICDA™

      BSM product

      Sovereign-facing decision support for converting announced capital into bankable, deliverable assets. Built for FMITI / NIPC-style pipeline governance: stage visibility, bankability flags, conversion probability, funding links, and network signal across projects, states, and funders.

      Technical scope

      • Client-side SPA (static assets, no server runtime)
      • 65-project demo corpus with delivery stages, progress, bottlenecks, timelines
      • Leaflet map with state-labelled sector markers
      • Visual delivery funnel + pipeline stepper profiles
      • Unified searchable / priority-filtered / paginated pipeline table
      • USD↔NGN display at CBN reference (1 USD = 1,347 NGN as of 3 Nov 2026)
      • Network graph: project ↔ state ↔ funder ↔ FMITI edges; optional Venn layout
      • PWA shell (manifest + service worker) for installable offline shell

      What it is not

      Not an official FMITI or Federal Government dataset. Demo stages, dates and funding mixes are simulated for product illustration.
